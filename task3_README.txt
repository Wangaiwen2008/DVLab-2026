任务三：MNIST 手写数字识别项目说明文档

一、 整体实现思路
这个项目的任务是让电脑学会认出手写数字（0到9）。我使用的是 PyTorch 框架，主要分为四个步骤：
第一步是准备数据：用代码自动下载了 MNIST 数据集，并把它转成了模型能看懂的张量格式。
第二步是搭建网络：我写了一个最基础的全连接神经网络（SimpleNet），包含一个输入层（把28x28的图片展平成784个像素）、一个隐藏层和一个输出层（输出10个数字的概率）。
第三步是训练：把图片喂给网络，计算误差（Loss），然后让优化器去调整网络，这个过程重复了2轮。
第四步是测试：用一批网络没见过的图片去考验它，看它认得准不准。

二、 程序运行中遇到的报错和易错点分析
1. 环境未激活导致找不到 torch 模块：
刚跑代码时，终端报了 ModuleNotFoundError: No module named 'torch'。排查发现是因为新开终端时默认在 (base) 环境，而我之前把 PyTorch 装在了专门建的 (agri_ai) 环境里。解决方法是先用 conda activate agri_ai 激活环境再运行。
2. 数据集下载失败（404报错）：
刚开始跑的时候，终端里提示 yann.lecun.com 这个网址报了 HTTP Error 404: Not Found。这是因为官方原链接偶尔会失效。但是 PyTorch 框架很智能，它自动帮我切换到了亚马逊的备用链接（ossci-datasets），并成功下载，所以不需要我去手动干预。这是一个很棒的底层容错机制。
3. 张量维度不匹配（理论易错点）：
在写网络代码时，输入层是 784 个节点，所以代码里必须加上 x.view(-1, 28 * 28) 把二维图片展平，如果不写这句，输入维度和网络定义不匹配，程序就会报错。
三、 程序运行结果
经过 2 轮的训练，Loss（误差）从最初的 2.3136 迅速下降到了 0.1317。
最终在测试集上，我的模型跑出了 96.12% 的准确率。

任务四：开放性自主 Demo 创作说明文档

一、 创作的背景想法
做完前面的任务三之后，我的模型只在黑框框里跑出了一串数字（准确率），我感觉太抽象了。我就在想，能不能像平时用的软件一样，弄一个能弹出来的窗口，让我用鼠标画个数字，它直接告诉我这是几？所以我就去问 AI，AI 告诉我可以用 Python 自带的 tkinter 库做一个画板。

二、 开发用到的工具和环境
系统就是我的 Windows 11 电脑。
代码是用 Python 写的，用到了 PyTorch 框架（用来加载我昨天训练好的那个 96% 准确率的模型），还用到了一开始装环境时装的 pillow 库，以及 Python 自带的 tkinter 界面库。

三、 开发过程遇到的问题以及解决办法
1. 图片大小和颜色对不上：
我一开始画完传给模型，它直接报错或者识别全错。后来我才搞明白，我的画板很大（280x280），而且是白底黑字；但是昨天训练的 MNIST 数据集，图片是很小的一张（28x28），而且是黑底白字。
解决办法：我查了 AI，在代码里加了几步处理。先用裁剪把数字抠出来，缩放到 20x20，放到 28x28 的中间，最后用代码把黑白颜色反转过来了。
2. 画了“2”却被认成“5”：
Demo 跑通后，我很兴奋地画了一个“2”，结果它告诉我这是“5”。我一开始以为代码写错了，后来发现，是因为我用鼠标画的线条太粗了，而且有点歪，和数据集里那些标准的手写体不一样。
解决办法：我技术有限，暂时没法解决这种识别偏差。我能想到的笨办法就是，自己在画板上写稍微细一点、工整一点，准确率就高很多了。可能以后学了更深的知识能解决吧。
四、 思考
1. 为什么做这个 Demo：因为我觉得能把死板的模型变成一个能互动的软件，非常有成就感。我也想向别人展示，我不仅会跑代码，还能把代码变成看得见的东西。
2. 怎么规划流程：先搞懂怎么把模型存下来，再搞懂怎么把画板上的线变成图片，最后把图片变成模型能看懂的格式，把它们拼在一起。
3. 对“技术只是一种工具”的理解：以前我觉得写代码、搞AI是件特别神奇甚至有点吓人的事，感觉离我很远。但这次做 Demo 我发现，tkinter 只是画框的，PyTorch 只是算数的。它们就像锤子和钉子，真正重要的是我知道我想做一个“画板”，然后去查怎么用这些工具实现它。工具本身再复杂，也是被我指挥的。
五、 开发进度说明
目前已经完成的部分：窗口能弹出来、鼠标能画画、点击按钮能成功把画板数据传给模型并显示预测结果。
还没做完或有缺陷的地方：
1. 界面太难看了，就是纯白色的粗糙框，没有美化。
2. 遇到线条太粗的连笔字，识别准确率不高。
3. 每次点“识别”的时候会卡顿一下，我猜是因为每次都要重新加载一遍模型，我还不知道怎么优化。
